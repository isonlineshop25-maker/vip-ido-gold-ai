# VIP IDO GOLD AI

Demo-goudbot (papertrading) met zeven stemmende bots, een scorebord en een "Klaar voor echt geld?"-meter.

- Installeren en gebruiken: zie [INSTALLEREN.md](INSTALLEREN.md).
- Updaten op de server: `ido-update`.
- De code van de server staat in `ido/` (Python, geen extra pakketten nodig). Tests: `cd ido && python3 -m unittest`.
